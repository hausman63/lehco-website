Faceless Video Publisher

A private publishing tool operated by LEHCO · Last updated August 21, 2026

What this is. Faceless Video Publisher is a small private command-line tool that uploads and schedules LEHCO's own short videos to LEHCO's own YouTube channel. It is not a product, it is not for sale, and it has no users other than its owner.

What it does

Every LEHCO short is produced locally — script, narration, illustrations, and final render. This tool performs the last step: it uploads the finished video file to YouTube and sets it to publish at a chosen time.

That is its entire function. It does not browse, search, play, download, or analyse YouTube content, and it never touches any channel other than the ones its operator owns.

How it uses YouTube API Services

This application uses YouTube API Services.

It calls the YouTube Data API v3 with exactly two permissions:

  • youtube.upload — to upload a finished video and set its title, description, tags, scheduled publish time, and its altered-or-synthetic-content disclosure.
  • youtube.readonly — used for one purpose only: to read back the name of the channel the credentials belong to, and display it as a confirmation before uploading, so that a video intended for one channel cannot be published to another by mistake.

Synthetic content disclosure

LEHCO shorts use AI-generated illustrations. Every upload made by this tool sets YouTube's altered-or-synthetic-content flag automatically, on every video, without exception. Disclosure is built into the tool rather than left to a person to remember.

Data handling

The tool stores no Google user data beyond a single local authorization token on its operator's computer. Nothing is transmitted to third parties, sold, used for advertising, or used to train any model. Full detail, including retention and deletion, is in our Privacy Policy.

Access can be revoked at any time at myaccount.google.com/permissions.
