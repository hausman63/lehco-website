What this website collects

Server logs

This site is hosted on GitHub Pages. Like nearly all web hosts, GitHub records standard technical information when a page is requested — IP address, browser type, and the page requested — for security and operational purposes. We do not control that logging and do not receive those logs. GitHub's handling of that data is covered by GitHub's Privacy Statement.

Your email address, if you give it to us

If you enter your email address to join the LEHCO list, we use it for one thing: sending occasional LEHCO updates. We do not sell it, rent it, trade it, or hand it to advertisers. Ask us to remove you and we will, no questions.

The LEHCO publishing tool and Google user data

Separately from this website, LEHCO operates a private internal tool called Faceless Video Publisher. It exists to upload and schedule our own short videos to our own social channels. It is not offered to the public and has no users other than the owner of this site.

What it accesses. The tool uses YouTube API Services. It requests two permissions: the ability to upload videos (youtube.upload) and read-only access to basic channel information (youtube.readonly). The read-only permission is used for exactly one purpose — to display the name of the channel being published to, as a safety check before an upload, so a video for one brand cannot be posted to another brand's channel by mistake.

How that data is used

  • Google user data obtained through these permissions is used only to upload, schedule, and confirm our own videos on our own channels.
  • It is not transferred to any third party, sold, or used for advertising, and it is not used to build profiles of anyone.
  • It is not used to train any machine learning or AI model.
  • No human other than the site owner reads it.

How that data is stored

The authorization token the tool receives from Google is stored locally on the owner's own computer, in a file that is excluded from version control and never uploaded anywhere. No Google user data is stored on this website, on GitHub, or on any server we operate.

How that data is retained and deleted

The tool stores no database and keeps no archive of Google user data. The only Google-derived data that persists anywhere is the OAuth authorization token, held in a single local file on the owner's computer.

  • Channel information read before an upload is held in memory for the duration of that upload and is never written to disk.
  • The stored authorization token is deleted by deleting that local file, which the owner can do at any time. Doing so ends all access immediately.
  • Tokens are automatically invalidated by Google when access is revoked (below), when they expire, or when the password on the Google Account changes.
  • No Google user data is retained after access is revoked, because none is stored in the first place.
  • Videos uploaded by the tool are the owner's own content on the owner's own channels, and can be deleted at any time from YouTube Studio.

How to revoke it

Access can be withdrawn at any time from the Google Account permissions page at myaccount.google.com/permissions. Revoking access immediately and permanently ends the tool's ability to reach any Google data.

Because the tool uses YouTube API Services, its use is also governed by the YouTube Terms of Service and the Google Privacy Policy.

Changes to this policy

If this policy changes in a way that matters, we'll update the date at the top of the page. We're not going to quietly rewrite it and hope nobody notices.
